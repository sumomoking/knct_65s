概要

概要

このゲームは2人から4人でプレイします 。1プレイは3ゲームで構成されます 。プレイヤーは相手の伏せられたカードの数字を推理し、当てていきます。

準備

1.0から11までの黒カード12枚 と、0から11までの白カード12枚 、およびポイントチップ を準備します。
2.親は白黒のカードをすべて裏向きでシャッフルし、山札として中央に置きます 。
3.各プレイヤーに4枚ずつカードを配ります 。
4.配られたカードは、自分から見て左から右へ、数字の小さい順に一列に並べます 。
※同じ数字がある場合は、「黒の方が小さい」というルールで並べます 。

ゲーム進行

1.親から手番を開始し、時計回りに進行します 。
2.手番プレイヤーは山札からカードを1枚引きます 。このカードもルール通りに自分の列に加えます 。
3.次に、自分以外のプレイヤーのカードを1枚選び、その数字を予想します 。
4.予想されたプレイヤーは、結果が真（当たり）ならカードを「オープン」し、偽（ハズレ）ならそのままにします 。
5.予想したプレイヤーは、以下のように行動します。
・予想が真（当たり）の場合：「他のカードを選ぶ」（続けて3の行動を繰り返す）か、「次のターンに進む」かを選べます 。
・予想が偽（ハズレ）の場合：自分が2で引いたカードを「オープン」し、次のターンに進みます 。

ゲームの終了と勝者

1.上記の手順を繰り返し 、全てのカードがオープンになったプレイヤーは負けとなります 。3人以上の場合、順位が決まるまで続けます 。
2.予想が成功すると、当てた人は相手から10点もらえます（当てたカードが「6」ならボーナスでさらに10点） 。
3.ラウンドの勝者は、「残った（オープンでない）カードの枚数」×10点を、他のプレイヤー全員からもらえます 。
4.カードの並べ方を間違えたり、予想に対して嘘の回答をしたりするとペナルティ（失格）となり、全てのカードをオープンしなければなりません 。
